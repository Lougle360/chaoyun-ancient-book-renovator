# 作者口吻的现代白话配图样张

适用于用户已选定“配图＋现代白话文、作者口吻、不需要批注”的阅读方向，或要求按这一方向再测指定页。整书也可采用同一表达方式，但仍执行整书合同。本文件不新增 workflow 版本、不改变验收脚本，也不把“精品”名称当作质量等级。

## 先确定范围与来源

- 以这次明确给出的文件、页码为准；沿用旧案例前核对源文件哈希、PDF物理页与印页映射，避免拿相邻案例或同名旧稿替代。
- 清点正文、旧注、图中说明、所有图组及子图，恢复跨列、跨幅、跨页接续。当前校订稿与继承OCR有分歧时回到原图及实际裁决，不能因旧文件名为 source 就把已纠正错误重新带入。
- 明确选页样张、选段样张或整章范围，保留稳定源块ID和对应裁片。内容到阅读页可以多对多；不能用“19项有去向”等计数冒称每一原字都已转换。
- 已有可信校读可复用，但应核对它是否覆盖本轮文字和图。原版式、古今对照、连续阅读是不同检查目的；不为制作一个读者样张机械重做所有历史版本，也不绕过用户已经要求但尚未完成的审核。
- 用户允许暂跳时，逐项记录被跳过的原文位置、原因、对表达完整性的影响和保留证据。中心观点缺证据时缩小并明确范围，或停在未通过状态；不能拼成看似完整的新论述。此次授权不外推到以后其他书或整书的删节。

## 正文如何写

遇到咒文、祝词、固定口诀、符箓题字或生僻字，先执行[原文／白话／图像处理规范](text-image-and-rare-glyph-policy.md)。下面的简体白话原则适用于说明性内容，不覆盖需保留原字原句的固定文字或构形字迹。原咒放在正文，旁白独立说明；不因为用户选择“作者口吻、不需要批注”而删掉原咒，也不把整段原咒做进图片。

直接表达原作的思想、判断和关系，采用现代简体横排。避免每段重复“原书说、作者认为、编者提示”，也不虚构古作者的新经历、口头禅或无来源观点。传说仍是传说，传统判断保留其语境，不升级为当代事实保证；作品及版本层面的归属可由标题、版本说明承担。

保留主语、条件、程度、否定、比较、因果、数量及方向。源正文与旧注中承担意义的内容可融合为连贯白话，融合不等于删除。难词优先在首次出现的句子内轻释；用户没要教学版时，不额外制造练习、课程目标、批注栏和通用知识百科。

原页存证、校记、审核问题、工具提示词放入内部材料。新创的解释、阅读图与源信息的边界仍须可追溯；如图的性质可能误导读者，采用最小必要的图题或版本说明，不把精确摹本与概念示意混为一谈。

## 配图按信息性质制作

| 内容 | 合适路线 | 必须核对 |
|---|---|---|
| 山脉、山形、自然景物、传说情境 | 用可用图像生成工具制作有形态与质感的阅读插图；已有适用素材可复用 | 与源图的主要结构、方向、连接和正文含义对应，不能只追求视觉气氛 |
| 数量、点阵、卦爻、九宫、精确方位、普通说明性标签 | 优先用矢量或程序排印，必要时叠加到生成插图上 | 从最终PDF重新核数、读爻、核名与位置；不能只检查配置里的正确数组 |
| 符箓、特殊符字、连笔及构形题字 | 保留原形、笔势、位置和连接；依据明确时另作忠实摹示 | 不改简体或现代字体，不猜补残笔；源图与摹图分别留存 |
| 混合型图 | 生成工具负责景物，排印负责精确信息 | 标签、符号和景物逐组对应，没有图像裁切或重排造成的错配 |
| 残损或含义未定的图符 | 原扫描保存；有充分依据时另作明确用途的阅读图 | 新图不能被用来反证原图残损笔画已经恢复 |

图像生成遵循当前可用工具及图像技能；记录实际工具、参考图、完整提示词、输出或复用来源。不能把本轮复用的图片写成“全部重新生成”。同一素材进入新排版后仍需检查图意、裁切和标签。

对于山形，保留有证据的轮廓与关系，并表现山脊、坡面、起伏等读者实际要理解的对象；不要把山脉画成无语义的几何符号。概念性植物循环、景物意象则须说明其内部来源和用途，不能据此增造原书的自然科学结论。

## 版面按阅读主题展开

一个主题配一组有作用的图与连续正文；根据内容拆页或合并，不固定页数、段数或字号。一个原页可以展开成多页，一组图也可同时服务两个主题。清点图组与子图，避免漂亮主图掩盖缺图。

同一语义区域保持统一字体、字号和基线，小注可采用独立且稳定的字号。不按单字OCR墨迹框拉伸字形。原版式校订检查原列序与位置；现代读者版按阅读顺序重排，两者不要共用“像素级还原”的宣传结论。

## 样张交付与实际审核

可使用既有样张目录结构；至少保存：指定源文件或哈希引用、源页图、现行校读依据、正文与图组的去向表、范围及暂跳说明、白话稿、素材来源、PDF及逐页预览、审核记录。已有统一疑点台账继续使用，样张中的说明引用原问题ID，不另建互相矛盾的关闭结论。

1. **源义检查：** 核对每个选定正文单元、图中文字和有意义的旧注；重点检查专名、条件、数位、顺序及相邻概念的区别。已经辨清字形但尚未解释的关系继续未决。
2. **读者检查：** 使用一次实际的独立模型调用或子代理审读选定样张，本合同授权这一有限的样张审读委派。先只给当前正文、实际PDF渲染和自然的理解任务，保存真实回答后再提供原页与校读证据进行源义比较。题目从本样张的真实难点产生，不预设答案，不要求固定题数。修订后审查改变的内容及相关上下文；记录模型或真人身份，没有独立执行就不声称独立通过。
3. **成品检查：** 逐页查看实际PDF渲染，检查字体、溢出、遮挡、文字完整、图位、图中文字和符号。适用时核对嵌入字体、可搜索文字与书签。点数、阴阳爻、方向与连线等高精度内容应从实际成品读取，结构检查不替代语义和视觉判断。
4. **绑定与交付：** 记录源PDF、正文、使用素材、最终PDF的哈希；确保已审预览来自该PDF。任何内容或图形修改后保留旧记录，针对当前字节重新核查；不靠刷新旧哈希延用结论。结论明确为本次范围内样张，可保留公开说明的局部未决；不能称全书定稿。

不要把审核者的“可供用户审阅”写成用户亲自满意，也不要将另一本书、另一页的认可移给本样张。整书生产试样还须补齐 [reader-production.md](reader-production.md) 中的生产计划绑定、正式读者会话及其他前置条件后才能扩展。

## 本项目已验证的教训

以下来自《三白宝海》印186页的具体失败与修订，用于识别类似风险，不是通用替换字典或每次必须复现的数字清单。

| 案例 | 可复用的判断 |
|---|---|
| “伏义”校为“伏羲” | 校正完整专名，不能全局替换“义”。 |
| “地数三／十”分处上下幅 | 先恢复接读，再解释天地之数。 |
| 本页“次坎、次离”曾按熟悉文本写成“次火、次水” | 原图字形优先；辨字结论不自动解决图文空间对应。 |
| 洛书旧重绘将“九紫火”等换成“坎水”等 | 精美重绘可能改变知识内容；图内文字需要单独核证。 |
| 洛书四数示意省略四隅和中央 | 四个位置正确仍不等于整图完整；旋转小字并结合实际同书证据。原图数位错误当时未获证实。 |
| “坎结束这一轮劳作”与“艮完成一轮”重叠 | 用试读发现概念冲突；根据原句与古注，将归藏休息和完成新始区分。 |
| 六页样册的河图55点、九宫九格、先后天16组三爻 | 检查实际PDF对象与可见结果；这些数只属于该样册，不成为别书的固定标准。 |

本页暂跳的图位、特殊图符、磨损点线、模糊色名与先天顺逆操作仍保留原证据。新增清楚的阅读图只解决阅读表达，不能顺带关闭这些源证据问题。
