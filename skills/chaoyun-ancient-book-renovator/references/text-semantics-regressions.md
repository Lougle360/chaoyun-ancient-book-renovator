# 真实失败案例：用于方法回归，不是替换字典

来自《地理天机会元》中册印页3、475、596的V1→V2复核（2026-10-29）。该次中册扫描的PDF物理页分别为4、106、226；已核对的页码映射不能外推其他版本。以下旁证来自该次实际查看的同书扫描。

| 场景／原字 | 错误行为 | 应有处理与证据 |
|---|---|---|
| 申乃乾之兄、壬不逢乾、酉巽乾亥 | OpenCC将孤立乾改为干 | 方位／卦名保留乾；其余普通干字不回改，乾燥等普通词另按语境转换。 |
| 弃节、弃卯 | 上一版“智能校正”为并节、并卯 | 撤回误改，按原扫描恢复弃。取舍关系是语义关键，顺口不能代替字形。 |
| 馬能；獨水天眷 | 为通顺改烏能、獨沐，并写入source | 忠实源层恢复馬、水；乌／沐仅为待核校读。关闭转写错误不能顺带关闭词义疑点。 |
| 天蓋換 | 因文义不通写天蓋□，或据相邻图题强补鬼 | 換字可辨，源层照录；鬼／格的拟校未唯一确定，不是“缺字已补齐”。 |
| 附寸金新 | 当作OCR新／赋混淆 | 目录确实印新；同书上册印271（物理279）大标题“附謝子敬寸金賦”。仅校读层作赋，记底本讹字。 |
| 金亟賦；卯集十二卷 | 仅凭熟悉书名或数字顺序猜改 | 同书上册印301（物理309）正文大标题“金函賦”、侧署卯集、卷之十一。校读函、十一，源字保留亟、十二。 |
| 四十二鬼名多瓶 | 模型顺句或误称原图为金 | 本页图题、古注及中册印581（物理211）平行正文均为金瓶。可据证校多为金；源层仍为多。 |
| 頭足爬／沙向后飛 | 把沙当未识字或改砂 | 跨列读爬沙，中册印580（物理210）同文互证；无需改字。 |
| 上雲／衢；出人／右 | 孤立衢为疑字，将右解释成右图 | 恢复云衢、出人右的完整接读；后者是超过他人，与小注起首“右…”区分。 |

| 四三鬼星名天蓋 | 自动补十以“修复序号” | 本页、邻页序列及印581同文支持省写四十三；正文保留四三，说明中解释。 |
| 謝覺齊 | 联想现代姓名改觉哉，或无证改斋 | 同书上册印257（物理265）“覺齊老人 謝和卿著”支持别号式署名；原字不改。 |
| 六六春、金心；亲娃夺权；以矣玄章 | 为可读性造出流畅句子 | 当次仍无唯一有据校读，保留字面与未决。论水核心句义为高影响，不能宣称内容通过。 |
| 同列T17上段、T23下段 | 按近似x坐标排序，误使下段在先 | 原坐标与稳定block_id保留；修正语义次序并接读邻列。本例T04→T17→T23→T11，不将样例ID写成所有书的规则。 |

真实结果：当次32项候选中19项具体纠错／确认／结构判断获独立复审支持，13项仍未决；19项不等于19个字，也不是全文无误。本表不授予之后任何书稿通过，不固定后续任务必须发现相同数量的疑点。

新方法可用同类未看过的章节检验：首次审阅不给预期读法，观察是否保留原字、找到实际旁证、连接跨列、识别语义未决及撤回自身误改，再对冻结成品复审。复述本表不能充当独立试验。
