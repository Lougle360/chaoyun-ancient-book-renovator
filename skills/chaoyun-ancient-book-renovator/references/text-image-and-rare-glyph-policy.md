# 原文、白话、图像与生僻字的处理规范

适用于含固定诵读文字、符箓、图内字迹或难字的古书，以及用户反馈重要原文遗漏的返工。普通说明文字继续走白话阅读路线，不把所有古文改成古今对照。本规范补充 workflow 1.10 的处理决策与实际审核，不新增阶段、不升级旧书验收，也不代表生僻字已自动识清。

## 先判断功能，再转换文字

同一源块可以同时有咒文、操作、小注；按有证据的边界分别处理，不因整块被标为 body 或 prayer 就使用同一种转换。原字保留、繁简转换和白话翻译是不同决定；保护项在繁简转换之前确定。

| 内容及功能 | 阅读层处理 | 文字与图片的边界 |
|---|---|---|
| 叙事、原理、用途、操作、条件、禁忌、因果说明及有意义的古注 | 转完整现代白话；保留主语、否定、先后、范围、数量、身份、后果，不用摘要代替 | 正文；长说明、旁白、标题与图注另排文字 |
| 咒文、真言、祝词、召请、宣令，以及其他以原措辞执行或诵读的文字 | 保留原字原句，含繁体、异体、重复字、起结、称谓与有作用的字序；另写旁白解释能确定的意思 | 可选择、可复制的正文；不把整段咒语留在插图或扫描图片里代替文字 |
| 歌诀、口诀、韵文 | 按实际用途判断：陈述道理可白话；用于诵念、传承固定口诀或字序本身承担内容时保留原文并解释 | 正文；不因押韵就全留，也不因难懂就全译 |
| 神名、专名、书名、术语、器物名 | 保留原称及本书所指，必要时首次轻释；是否简化单独按语境决定 | 普通文字在正文；原图已有题字同时按其图内作用处理 |
| 符箓、符胆、特殊符字、连笔、笔画与文字共同构形的题字 | 保存原字形、笔势、朝向、相对位置及连接；不做繁简替换或现代字体重排 | 留在图内；旁白可解释已有依据的内容，但不能代替原图字迹 |
| 山脉、山形、器物、方位、卦爻、点阵与关系图 | 依图型重绘或精确排印，核实轮廓、数量、方向、连接与层次 | 必要短标注随图定位；一般解释性标签可简化，精确信息单独排印，长解释回到正文 |

“姜太公在此”一类题字若属于符牌原迹，应保留原形；正文引用与解释可以另按阅读政策处理。不能把这条例子推广成所有图题均不简化。使用朱砂、黄纸、毛笔或黑墨，依据本书证据和用户已确认的表现方案决定，不给所有历史书统一上色。

固定文字的识别错字可以依据原图纠正；底本本来如此时保留其字面。不能因习惯式样而把“大上”改成“太上”、把“急急律令”补成“急急如律令”。这些是已遇到的错误类型，不是通用字词替换规则。句读和分行可以为阅读而加，但不得改变字序、重复次数、分项关系或操作边界；有歧义的句读继续保留未决。

## 接入现有流程与记录

1. **诊断／原貌重建：** 清点正文、古注、图、子图、图内字、咒文和操作；恢复跨列跨页接读，登记固定文字与构形字迹的保护范围。尚未决定功能的片段暂保原貌，不先做不可追溯的简化或改写。
2. **文字规范：** 普通说明按已定目标文字转换；保护范围原字透传，记录保留理由及边界。混合块按片段处理，不先整块转换再凭记忆还原。
3. **全书理解／阅读设计：** 在整书配图方案中明确哪些内容为正文、原咒、旁白、符图、普通标签，核实图与文字的关系。代表样章优先验证实际存在的混合段、符咒关系或难字；无此类材料不制造测试对象。
4. **今译／编辑：** 译说明、留固定文字、写独立旁白，按完整阅读单元组织。不因选择“作者口吻、无需批注”而删除源咒；旁白解释属于读者需要的正文，校勘过程和候选字列表留在审核材料。
5. **读者复核／出版：** 分别审语义完整、固定文字完整、图形完整及配用关系；检查实际MD与PDF，不能只检查输入JSON和图数。

沿用现有源块、变更账本、配图清单、阅读单元和源稿映射，不另建竞争的疑点账本，也不擅改 reader-units 的合法 kind。对适用片段，记录至少能回查：源块及片段位置、文字功能、处理决定、依据、保护范围、对应图／操作和阅读去向、未决ID。可以把这些决定记在既有记录的说明中或作为被引用的补充表；机器结构通过不证明这些功能判断正确。

## 符、咒、操作和旁白如何对应

- 先核对“念某咒”“书此符”“书毕大喝曰”等指向、段落边界及跨页续文。按实际证据区分直接配用、同一操作链、底本未提供、指向未定；空间相邻或名称相似不能单独证明配对。
- 有明确关系时，把符图、原咒和独立旁白安排在同一阅读单元。篇幅过长可分相邻页并明确承接；必要的重复配图要说明用途，不能被图数检查当成新增原图。
- 操作次序也是内容：先贴符、后念咒，或先书毕、再宣令，不得因排版改变。原小注、人物填写模板与诵句要分清；原注在咒文中间时保留其位置并以版面区分。
- 源文把“暗诵七遍”等操作性文字与咒段连排，而界限未确定时，保存该字串并在旁白解释，不能自行删出、移位或声称它确定属于／不属于诵句。
- 没写配咒，注明本节未载，不能推出“此符不需要咒”。只提秘符名却无可确认图形，不借邻图代配。只说诵某经一卷，不从其他版本擅自补入整卷。
- 原咒、祝词、宣令的名称与引导语也在核对范围内。旁白说明这段在当前法式中的意思和作用；不改原咒，不给未定咒音编读音，也不把残句解释成确定的完整指令。

## 网上查不到的字：区分问题再处理

搜索无结果不等于不存在这个字，也不证明它是错字。记录实际检索范围，不声称查遍全网；用过的字书或异本须实际查看相应字形和上下文，不把搜索摘要、其他AI回答当字形证据。

| 问题 | 应做的事 | 不应做的事 |
|---|---|---|
| 原字清楚，编码及读法已确认，仅字体缺字 | 使用覆盖该字的字体并嵌入PDF；实看渲染并检查复制结果 | 因字体方框而改成近似常用字，或把它登记为源文缺字 |
| 字符身份已确认，读音或字义未定 | 保留该字符，分别记录未定音义；必要时查可靠字书及版本证据 | 因不知咒音而删字；把现代字音当作已证实的咒音 |
| 原字清楚，不能唯一映射字符 | 保留真实单字字形；可用源字裁片或忠实字模按正文基线嵌排，标明未释；再查同书字形、异本及可靠字书 | 因查不到就把清楚的字换成□，凭部件编读音，擅认某个标准字 |
| 字认得，文义不通 | 源层照录，另登记词义／句读疑点；旁白只解释确定的部分 | 为通顺悄改字，或关闭字形问题时顺带关闭词义问题 |
| 原字残损但仍有笔画可见，无法唯一辨读 | 保留真实残形并嵌排，明确它不是完整字；找更清楚扫描、同书复现或可靠异本 | 有残笔却一概换成□；生成式补笔或把短残片拉满字位 |
| 确知单个字位却没有可用字形，或连续损段字数不明 | 保留源区；前者用□，后者用〔缺损〕。已知多字位按可证数量记录 | 把不识当作缺失，把未知长度损段压成一个字位，按常见咒式补全 |
| 特殊符字、云篆或多笔连构，不宜作普通字符 | 作为符文图形保存，说明能确定的角色及关系 | 强拆成普通汉字、虚构Unicode映射或咒音读法 |

单字字模只保存已看见的形，不补造看不见的笔画。每个特殊字形保存稳定引用、源页／坐标、源片及派生字模哈希、所在正文位置和已知读法状态。若用私有字模或单字图片，须保留字形映射；不能宣称未有字符对应的字也可按标准汉字搜索或无损复制。复制回退值不得偷偷放入猜字；阅读版做最小必要说明，完整映射留在证据包。

**单字嵌排与整段图片化不同：** 无可靠字符映射的原字或真实残形可嵌入正文，其余文字正常排版。不能用整段扫描代替可排原咒，也不能为了“全部可复制”牺牲真实字形。□与〔缺损〕是编校标记，不属于原咒；标记保留不等于疑点已解决。候选读法可以记在内部账本，但不能塞进原咒让读者误当诵词。

仍无法判断时，执行[原字保形、残形与缺损兜底](glyph-fallback-and-acceptance.md)：保存真实裁片及映射，核对嵌排、PDF 实际复制字序，并分别给出“原形保存”和“咒音完整还原”的结论。复查已转录的普通汉字，不能只处理原先的□；无依据的旧映射也要退回真实字形。用户验收绑定具体版本及约定范围，不替代未决音义的证据。

同书互证、可靠异本与上下文结合使用；上下文只能约束候选，不能独自证明某笔某字。中心含义仍未确定时保持未通过或明确的试读状态；缺少新证据时按既有无进展停止规则收束，不以反复生成获得“确定答案”。

## 实际成品的审核点

审读者分别回答以下问题，并把发现绑定到这次MD、PDF和使用的素材：

1. **意义是否完整：** 白话是否保留每个实质分句的条件、动作、数量、程度、身份、否定和结果？“代代”不能只剩泛泛“后人”，“宰臣”不能只剩“辅政”，“不可钉兽面”不能缩成“不可钉中央”。不把全文译成摘要，也不把所有原歌诀一律追加为对照。
2. **原文载体是否完整：** 原咒的标题、起结、重复字、跨列／跨页续字是否在正文中？逐字与已复核源文比对；只忽略明确的排版空白和有记录的句读，不使用繁简、异体归一来掩盖改字。插入的旁白和待考标记须明确区分。
3. **图与关系是否正确：** 每幅／子图及构形字迹有去向，没有裁掉符笔或新增猜笔；符咒与动作按证据对应。裁切只改变可见区域，不能写成“原素材已去掉咒文”。
4. **阅读与技术表现是否成立：** 实际PDF中，长咒文是可选择文字而非只藏于扫描的OCR层；实看原咒、旁白、图的位置和字体。MD同样有对应原文，引用符号在行首且段落分隔正确。特殊单字核字模、基线及复制回退，不能只查字体文件存在。

“100段已排进PDF”“56项图有去向”只能证明相应覆盖，不证明原文没有漏义、咒文未被改写或图形正确。明确报告本轮修订范围、仍未决的文字／关系及书稿等级；漂亮排版不能把C级试读稿变成正式定稿。

修改后复查实际新成品及受影响的上下文。可以保留未变内容的既有实质审读，但须独立验证新旧页像、文字及相关映射的等价性，保留旧文件和新绑定；仅刷新旧报告哈希不算复查。

## 《秘诀仙机》试制提供的反例

这些例子用于判断处理方法，不是所有书的固定内容或更正字典。

- 安家堂真言与开天咒只剩白话咒意：即使意思大致在，原文载体仍缺失；应补原咒、另排旁白。
- 瓦将军点眼被提前到祝词之前：操作未删也可能次序失真，须恢复“顯靈通”后的原注位置。
- 上梁段只有秘符名，十二月符节未写配咒：不得拿邻图或邻咒补成貌似完整的配套。
- “大上”“急急律令”被熟悉形式替换：固定原文应逐字保留；一般解释可另用现代语言。
- 清楚但不识的异体、字体缺字、真实墨污曾混为一类：分别使用保原字、换字体／单字字模、待考标记，不能一概□化。
- 源块计数及段落提取全部通过，仍可能漏标题、缩小禁忌范围或漏“深藏”“代代”等信息：成品检查须包含实际逐句比较。

该例只支持方法改进；没有证明所有残字已释清，也不授予新任务任何现成通过状态。
