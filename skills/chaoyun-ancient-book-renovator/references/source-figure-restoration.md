# 原书图像修复与精确重绘门槛

适用于含盘图、地图、器物图、山形图、符图、点阵、表格、图内题字或其他内容图的书，也适用于用户反馈“原图没有修复”“图被放糊”“图中文字看不清”的返工。目标不是把所有图做得平滑，而是在不伪造证据的前提下，让普通读者获得真正可读的图像。

## 两层资产不能互相覆盖

- **证据层原图：** 保存原 PDF 页图、原始裁片、像素尺寸、来源页／坐标和 SHA-256。永不覆盖，永不把修复结果冒充原始扫描。
- **阅读层图像：** 可以是修复后的原貌图，也可以是标注清楚的编者重绘。每个资产必须回查原图、源文和制作路线。
- 原扫描没有的细节不能通过锐化、生成式补笔或常识猜测变成“原书内容”。可确定的规则可以另作编辑重绘，但不得伪称修复原图。

## 先分类，再决定路线

| 类型 | 典型内容 | 必须采用的路线 |
|---|---|---|
| 原貌保留 | 印章、版式、污损本身有证据价值 | R0 保存；可另做阅读裁片 |
| 可修复栅格图 | 纸色不均、轻度噪声、线条虚弱、尺寸不足 | R1/R2 保守修复；保留灰阶和残损 |
| 可精确重绘技术图 | 方位、数字、卦爻、点阵、箭头、层级、关系图 | 原图修复供回查；另做 R3 确定性重绘 |
| 构形字迹或残字 | 符字、连笔、题字、可见残笔 | 保原形；不得生成式补笔；按难字政策处理 |
| 自然形态示意 | 山势、水势、器物外观 | 可修复、人工描绘或生成插图；精确标签另行排印 |

每一内容图和子图都要在 `10-diagnosis/figure-inventory.json` 中有稳定 `figure_id`、来源页／坐标、原尺寸、类型、阅读障碍、处理级别、成品去向和未决项。不能只登记“共 N 幅图”。

## 修复级别

- **R0 原貌保存：** 只复制或无损提取，不改变像素。
- **R1 基础整理：** 裁边、旋转／去斜、纸色校平、轻度对比度和色阶调整。
- **R2 阅读修复：** 在 R1 基础上做保守去噪、去模糊、无损格式放大、断线的小尺度形态增强；不得二值化吞字，不得生成缺失笔画。可使用 `scripts/restore_source_figure.py` 作为起点，但必须实看结果。
- **R3 编辑重绘：** 依据已校核的源图和源文，用 SVG、绘图代码或人工矢量方式重绘。数字、标签、方向、数量、连接和符号必须由确定性工具控制，不用生成式图像文字。

低清 OCR 缩略图直接放大、只裁空白、只做自动对比度、把 JPEG 改名为 PNG、或用生成模型“增强”盘内小字，都不属于合格修复。

## 必备文件与生产位置

全书任务至少保存：

- `20-source/pages/`：从原 PDF 提取或渲染的完整页图；
- `10-diagnosis/figure-inventory.json`：逐图清单与原图哈希；
- `40-modernized/restored-originals/`：R1/R2 修复图；
- `40-modernized/editorial-redraws/`：R3 重绘图；
- `50-edited/illustration-plan.md`：全书图像去向及阅读路线；
- `50-edited/sample/illustration-review.md`：代表图的实际页面复核；
- `90-audit/figure-restoration-contact-sheet.*`：修复前后对照；
- `90-audit/figure-restoration-review.json`：最终图像关卡结论。

原书图进正文还是附录由读者任务决定。技术图通常在正文使用 R3 重绘，附录保留 R2 修复原图；需要逐图比对时可并列。图注必须分别写“原书修复图”或“编者据原书规则重绘”。

## 最终关卡

在样章和最终 PDF 中实际检查，不以脚本成功或文件存在代替：

1. 逐图核对来源、裁切、旋转、图名、图中文字和子图数量。
2. 记录原像素、成品像素、排版尺寸和有效打印 DPI；禁止把低清图放大到文字失真的尺寸。
3. 技术图逐项核对数字、方位、箭头、卦爻、点阵、连接和层级；生成式图像不得承担这些精确信息。
4. 生成修复前后联系表，确认没有吞笔、连字、伪造缺笔或把污损误认成线条。
5. 渲染最终 PDF 全部页面，在 100% 检查整体版面，在 200% 检查图中文字、线条、裁边和图注。
6. 确认原始资产仍存在且哈希未变，修复图和重绘图有独立路径和标签。

任一内容图仍使用低清缩略图、R3 标签与已核规则不一致、修复图覆盖原图、或最终 PDF 未实看，均阻断出版关卡。源扫描本来不足以辨清的细节可以保留为有界限制，但必须由正文、表格或明确标注的编辑重绘解决普通读者的阅读障碍。
